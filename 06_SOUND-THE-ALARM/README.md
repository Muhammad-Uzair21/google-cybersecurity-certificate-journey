# 📚 Key Learnings

- Incident response lifecycle and incident handling
- NIST Incident Response Lifecycle
- Computer Security Incident Response Teams (CSIRTs)
- Security Operations Centers (SOCs)
- Incident response planning and exercises
- IDS, IPS, and EDR technologies
- Security Information and Event Management (SIEM)
- Log collection, normalization, and analysis
- Network traffic monitoring and packet analysis
- Incident investigation and evidence collection
- Security alerts and event management

# 🧪 Hands-on Learning

Throughout the course, practical activities focus on:

- Documenting security incidents
- Investigating suspicious activity
- Analyzing network traffic and packets
- Working with detection and monitoring tools
- Investigating logs and security events
- Applying incident response procedures
