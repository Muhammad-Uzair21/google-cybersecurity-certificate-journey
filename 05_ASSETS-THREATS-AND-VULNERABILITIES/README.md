# 🎯 Core Security Thinking

# 🚩 Attacker Mindset

Identify the target
        ↓
Determine how it can be accessed
        ↓
Identify exploitable attack vectors
        ↓
Understand tools and techniques
        ↓
Evaluate the risk
        ↓
Strengthen the defenses
